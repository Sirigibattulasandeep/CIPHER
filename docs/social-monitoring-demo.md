# Social & App Monitoring demo walkthrough

1. Create or select a brand. Add official profile URLs, domains, app listing
   IDs and publishers, plus a logo URL when available.
2. Open **Social & Apps** and select the brand and record type.
3. Load the demo records. The UI labels them **Simulated**. Explain that
   simulated rows are not observations of real threats.
4. Run a scan. Inspect the candidate with suspicious support or giveaway
   language and the lookalike app title, publisher, link, or supplied logo
   similarity. Explain the score from its evidence and confidence.
5. Filter by platform/store, source, record origin, and severity; search the
   evidence; then mark a finding **Investigating** and confirm the status is
   reflected in the queue and investigation page.
6. Import a JSON export to demonstrate user-supplied records. State clearly
   that connected-source monitoring, website verification, and image analysis
   are not active in this prototype.
