# Suggested prototype walkthrough

1. Create a brand profile for a KampusVC venture (or use the Northstar sample
   in the demo fixture) and configure its official social handle, domain,
   official store listing ID, publisher, and logo asset reference.
2. Scan the labeled demo profile and app records. Point out that the known
   official handle and exact official app ID are excluded from identity
   alerts, while their source remains marked as simulated.
3. Open the lookalike profile and app findings. Walk through the contributing
   name, support/official-claim, publisher, link, scam-language, and supplied
   logo-similarity evidence, including source URLs.
4. Import a JSON array of candidate records and apply platform, source,
   severity, or search filters to the resulting findings.
5. Explain that findings are screening leads for human investigation. No live
   monitoring, store access, website verification, logo analysis, or persistent
   investigation workflow is claimed by this prototype yet.
